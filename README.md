# MovieMania 🎬

MovieMania is a Machine Learning-based movie recommendation system built with Python and Streamlit. The application recommends movies similar to the one selected by the user using content-based filtering techniques.

📌 Features
- Movie recommendation system using Machine Learning
- Interactive and user-friendly Streamlit interface
- Content-based movie filtering
- Fast and responsive recommendations
- Clean UI for easy navigation


🛠️ Tech Stack
- Python
- Streamlit
- Machine Learning
- Pandas
- NumPy
- Scikit-learn
- Pickle


📂 Project Structure

MovieMania/


── app.py

── movies.pkl

── similarity.pkl

── requirements.txt

── README.md


▶️ Run the Streamlit Application

Use the following command to start the application:

streamlit run app.py

After running the command, the application will open in your browser.


🎯 How It Works
- Select a movie from the dropdown list
- Click on the Recommend button
- The system displays movies similar to your selected movie

The recommendation system uses similarity scores generated through Machine Learning techniques.
